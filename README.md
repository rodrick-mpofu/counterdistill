# CounterDistill

## From Local Counterfactual Explanations to Global Interpretability

A production-quality ML Engineering + Explainable AI (XAI) project that aggregates local counterfactual explanations into concise global explanations using clustering and interpretable model distillation.

## Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/counterdistill.git
cd counterdistill

# Install dependencies
make dev

# Train a model
make train

# Launch dashboard
make dashboard
